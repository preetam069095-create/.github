# Antigravity APK

1. Create a new empty GitHub repository.
2. Upload everything in this folder (keep the .github folder).
3. Open the Actions tab -> "Build APK" -> wait ~5 minutes.
4. Open the finished run, download the "antigravity-apk" artifact, unzip it.
5. Copy app-debug.apk to your phone, tap it, allow "install unknown apps".

To change the game, edit www/index.html and push again.
